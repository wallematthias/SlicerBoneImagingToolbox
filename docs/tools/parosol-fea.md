# ParOsol-FEA

ParOsol-FEA prepares and runs finite-element workflows from material label maps. The Slicer module handles scene selection, profile selection, output loading, and SED display. The `parosol-py` package owns workflow execution.

https://github.com/wallematthias/parosol-py

## Required Inputs

| Input | Meaning |
| --- | --- |
| Material label map | FEA material labels, usually generated by Contouring |
| Profile | solver and load setup |

For HR-pQCT workflows, the material label map usually contains trabecular and cortical material labels derived from bone segmentation intersected with ROI masks.

## Profiles

Common profiles include:

- `XtremeCT I`,
- `XtremeCT II`,
- `Load History 3`,
- `Load History 6`.

Each profile is treated as a separate output family. Running a load-history profile should not make the standard profile appear complete, and vice versa.

## Scene Mode

Use scene mode for one loaded material label map.

1. Select the material label map.
2. Select the FEA profile.
3. Run the workflow.
4. Load the SED field and compact mechanics table.

Loaded SED fields are restored to the selected reference grid when ParOsol outputs a cropped field.

## Batch Mode

Use `Bone Imaging > I/O > Batch Processor`.

Each row corresponds to one material label map and selected profile. Load-history profiles load scale factors and load amplitudes in addition to the SED and mechanics table.

## Outputs

Outputs are written under `derivatives/FEA/`:

- SED field,
- mechanics summary,
- solver files,
- load-history scale factors when the selected profile uses load history.

The loaded Slicer table should focus on study-facing values such as stiffness and failure load.
